# LM Studio + TypeSafe chatbot

Goal: a standalone Tkinter chat demo, with no NeuralCompanion modifications.

Design: TypeSafe Choice classifies the latest message's tone. Code maps that
choice to a gentle style hint; LM Studio generates the conversational response.
Unknown/uncertain tone uses neutral guidance. Classification failure is visible
and does not block local chat. Only the current user message goes to TypeSafe.
Conversation history remains in memory and goes to the configured LM Studio URL.

Implementation sequence:
- Write backend tests for composition, fallback, invalid responses and HTTP errors.
- Implement chat_backend.py using urllib, explicit timeouts and validated responses.
- Implement chatbot.py with masked keys, model discovery, chat history and clear.
  Workers receive immutable snapshots; only the Tk main thread touches widgets.
- Add start_chatbot.cmd and README.md with setup and manual verification steps.
- Run tests, a Tk lifecycle smoke test, and available live service checks.

No new dependencies, commits, saved credentials or conversation files.
